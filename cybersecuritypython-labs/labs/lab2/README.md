Завдання 1 — task_1.py

Модуль реалізує просту систему керування користувачами.

Основні можливості:

створення користувача User;

перевірка та зміна email;

встановлення пароля з використанням PBKDF2;

перевірка пароля;

деактивація користувача;

створення адміністратора Admin;

керування permissions адміністратора;

створення та перевірка сесії користувача;

автоматичне завершення сесії після таймауту;

ведення журналу подій AuditLog;

авторизація та вихід із системи через UserAccount;

доступ до даних UserAccount через [].

Паролі не зберігаються у відкритому вигляді. Для них використовується PBKDF2-HMAC-SHA256 із випадковою сіллю.

Завдання 2 — task_2.py

Модуль призначений для аналізу журналу активності користувачів у форматі CSV.

Програма:

читає CSV-файл;

перевіряє наявність необхідних колонок;

перетворює timestamps у datetime;

групує записи за користувачами;

знаходить активність у позаробочий час;

знаходить звернення до критичних ресурсів;

виявляє більше 50 GET-запитів одного користувача до одного ресурсу протягом 60 секунд;
формує список аномалій

записує результати аналізу у JSON-звіт;

використовує logging для інформаційних та помилкових повідомлень.


main.py використовується як головний файл, який запускає обидва завдання


Для запуску програми використовуються такі параметри командного рядка:

Призначення параметрів --activity-log data/activity.csv --after-hours --out-report data/off_hours_audit.json --log-file data/activity_audit.log:

--activity-log data/activity.csv — вказує шлях до вхідного CSV-файлу activity.csv, який містить дані про активність для аналізу.

--after-hours — вмикає режим перевірки активності, що відбувалася поза робочим часом.

--out-report data/off_hours_audit.json — визначає шлях і назву вихідного JSON-файлу off_hours_audit.json, у який зберігається звіт за результатами перевірки.

--log-file data/activity_audit.log — задає шлях до файлу activity_audit.log, у який записуються журнальні повідомлення про виконання програми.
